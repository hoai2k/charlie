# Riding-toy pickup replacements

Delivered R10, R12, R13 and R14. Source and prompt include two experimental
skate variants for Beach and Toy Room; the updated brief keeps those tracks'
surfboard and wind-up key, so only the other four cells are installed.

Each delivered 256px cell is replaced in the previously delivered full strip,
then saved with lossless WebP exact=True. `verification.json` records decoded
RGBA for all five cells; untouched cells match the before sheets byte for byte.
The standard track exporter reapplies the reviewed sources and checks them.
