# Party character references

Start with the [character design guide](CHARACTERS.md) for appearances, companion relationships, and suggestions for future animation and gameplay. Browse the [canonical gallery](canonical/index.html) to compare cartoon references with the original drawings.

- `drawing_*.JPG` files are the original children's drawings.
- `canonical/*.webp` files are the cartoon character references, with lossless artwork and transparency.
- `canonical/felicity-and-fellowfox.webp` and `canonical/kpop-girls.webp` show the two groups that always travel together. Each member also has a separate reference for sprite generation.
- `canonical/generation-manifest.json` records prompts and source images.

The 15 original character references and the additional Troll NPC reference define character identity. Group images supplement them with relative placement and scale. Troll is an occasional NPC only and will need separate sprite animations. Personality and gameplay ideas in the guide are suggestions, not established lore.
